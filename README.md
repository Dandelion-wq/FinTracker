# FinTracker — веб-приложение для учёта личных расходов

Перед установкой убедитесь, что ваш компьютер соответствует минимальным требованиям:

- Node.js
- npm — устанавливается вместе с Node.js
- PostgreSQL


## Пошаговая инструкция по установке и запуску

### Шаг 1: Распакуйте архив

Распакуйте полученный ZIP-архив в любую папку на вашем компьютере.

### Шаг 2: Установите Node.js

1. Скачайте Node.js с официального сайта
2. Запустите установщик и следуйте инструкциям (оставьте все настройки по умолчанию)
3. После установки перезагрузите компьютер



### Шаг 3: Установите PostgreSQL

1. Скачайте PostgreSQL с официального сайта
2. Запустите установщик
3. Во время установки запомните пароль, который вы укажете для пользователя postgres — он понадобится на шаге 6


### Шаг 4: Создайте базу данных

Способ 1: Через командную строку

1. Откройте командную строку
2. Выполните команду: psql -U postgres (введите пароль от PostgreSQL)
3. Создайте базу данных: CREATE DATABASE "FinTracker";
4. Выйдите: \q

Способ 2: Через pgAdmin (графический)

1. Откройте pgAdmin (устанавливается вместе с PostgreSQL)
2. Подключитесь к серверу (пароль, который вы указали при установке)
3. Кликните правой кнопкой по Databases → Create → Database
4. Введите название: FinTracker
5. Нажмите Save


### Шаг 5: Выполните SQL-скрипт

В корне проекта находится файл database_backup.sql — это бэкап структуры базы данных.

Способ 1: Через командную строку

1. Откройте командную строку и перейдите в папку с проектом:
   cd C:\путь\к\папке\FinTracker
2. Выполните команду:
   psql -U postgres -d FinTracker -f database_backup.sql
   (введите пароль от PostgreSQL)

Способ 2: Через pgAdmin (Restore)

1. Откройте pgAdmin и подключитесь к серверу
2. Кликните правой кнопкой по базе данных FinTracker
3. Выберите Restore...
4. В поле Filename нажмите на папку и выберите файл database_backup.sql
5. В разделе Format выберите Custom or tar
6. Нажмите Restore


### Шаг 6: Настройте файл окружения

1. В папке backend найдите файл .env
2. Откройте его в любом текстовом редакторе
3. В строке DB_PASSWORD укажите свой пароль от PostgreSQL:
   DB_PASSWORD=ваш_пароль_от_postgres
4. Всё остальное менять не нужно — настройки почты и JWT уже заполнены
5. Сохраните файл


### Шаг 7: Установите зависимости

Откройте командную строку в папке с проектом.

Для бэкенда:
cd backend
npm install

Для фронтенда (откройте новый терминал):
cd frontend
npm install


### Шаг 8: Запустите приложение

Потребуется два окна терминала.

В первом окне запустите бэкенд:
cd backend
npm run dev

Во втором окне запустите фронтенд:
cd frontend
npm run dev

### Шаг 9: Откройте приложение

1. Откройте браузер 
2. Перейдите по адресу: http://localhost:3000
3. Зарегистрируйте новый аккаунт:
   - Введите email 
   - Придумайте пароль (минимум 6 символов)
   - Заполните ФИО
4. На указанную почту придёт код подтверждения
5. Введите код подтверждения
6. Войдите в систему и начните пользоваться
